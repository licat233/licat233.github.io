MOST STARRED · OPENCORE · HASWELL

A minimal EFI for a very specific machine.

A compact OpenCore EFI built around 4th-generation Haswell i3/i5 systems with Intel H81, HD4400–HD4600 graphics and ALC662 audio. The repository emphasizes stability, small size and removing unnecessary patches.

01 / PROJECT IDEA

Less EFI, fewer moving parts.

The repository's own rule of thumb is simple: OpenCore does not get better by accumulating more patches and drivers. Stability matters more than chasing every new release.

01

Small by design

The README describes the EFI as reduced to roughly 3 MB by removing unnecessary patches and settings.

02

Hardware-specific

Built around Haswell i3/i5, H81, HD4400–HD4600 and ALC662 rather than pretending to be a universal EFI.

03

Stability first

The project explicitly argues that a working, stable OpenCore version is more useful than upgrading merely because a newer release exists.

03 / USE

Match the EFI to the system.

The repository carries separate EFI directories for different macOS generations. Installation notes also distinguish debug and production configuration files.

Before booting

Modify PlatformInfo for your own machine. Intel Wi‑Fi/Bluetooth and USB 3.0 may require additional patching depending on hardware.

Known limitation

The README states that everything was working on the author's office computer except iMessage.

The repository documents High Sierra through Monterey-era configurations. Its Ventura entry was still marked “under development” in the 2023 README, so treat it as a historical hardware-specific EFI project rather than current universal macOS guidance.

Why it remains featured

It is the most-starred public project in this portfolio: 26 stars and 5 forks at the time this page was created. More importantly, it captures a practical engineering instinct that still holds up — remove what is unnecessary, optimize for the actual machine, and stop changing a stable system without a reason.
