01 / 项目思路

EFI 不是越多越好。

README 里最明确的一条原则，就是 OpenCore 不应该靠不断堆补丁和驱动来获得“完整感”，稳定比盲目追新更重要。

01

尽量精简

README 记录这套 EFI 被精简到约 3 MB，移除了不必要的补丁和设置。

02

明确面向硬件

目标就是 Haswell i3/i5、H81、HD4400–HD4600、ALC662，不把它包装成万能 EFI。

03

稳定优先

项目明确提出：OpenCore 不是版本越新越好，能稳定使用时没有必要为了升级而升级。

03 / 使用

按自己的系统和硬件匹配。

仓库针对不同 macOS 世代保留了不同 EFI 目录，安装阶段和正常使用也区分 debug / product 配置。

启动前

必须修改 PlatformInfo。Intel Wi‑Fi / 蓝牙、USB 3.0 等是否需要额外补丁，取决于具体硬件。

已知限制

README 记录作者办公电脑长期使用时，除 iMessage 外其它功能正常。

仓库主要记录 High Sierra 到 Monterey 时期的配置；2023 年 README 中 Ventura 仍标记为“开发中”。因此更适合把它视为一份特定硬件的历史 EFI 工程，而不是今天所有 macOS 的通用安装指南。

为什么它仍然是精选项目

创建本页面时，它仍然是我公开仓库中 Star 最多的项目：26 Star、5 Fork。更重要的是，它保留了一种至今仍适用的工程直觉：删掉没必要的东西，针对真实机器优化，稳定以后不要为了折腾而继续折腾。
