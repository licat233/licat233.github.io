# Codex 高效使用的 10 个技巧

1. **侧边聊天 / side：** 执行任务时开临时提问，不中断主任务。
2. **更多详情：** 选中文字就能获取对应内容的补充解释。
3. **计划模式 / plan：** 步骤不明确时先讨论定方案再执行。
4. **目标模式 / goal：** 设定最终目标，让它持续推进任务。
5. **代码审查 / review：** 检查代码改动，找 bug 和对原有功能的影响。
6. **查看状态 / status：** 查看当前会话的上下文用量和状态。
7. **压缩上下文 / compact：** 对话过长时压缩，继续原有任务。
8. **分叉对话 / fork：** 保留原对话，开新分支换思路讨论。
9. **项目固定约定：** 把长期要求写进 AGENTS.md，项目内自动读取。
10. **复用 Skill：** 把成熟的固定流程存成 Skill，后续直接调用。

> 注意：这些是操作思路与常见功能名称。具体入口、命令、可用性会随 Codex 客户端及版本而变化，请以正在使用的版本为准。
