PRINCIPLES

How I Build

Technology is a means. A good system should make the work simpler, not make people adapt to the system.

◎01

Real Problems

Start from an actual need or friction point, not from a technology looking for a problem.

◇02

Smallest Sufficient Solution

Reuse mature capabilities when possible; if a smaller solution is enough, don't introduce a larger system.

↻03

Maintainability

Deployment, upgrades, rollback and long-term maintenance are part of the product, not afterthoughts.
