# 开发轨迹 — GSAP 动画隔离预览

> **仅供审阅**。不修改 `index.html`、`zh/index.html`、`en/index.html` 或任何正式主页动画文件。未经视觉审阅和明确批准，不合并此预览至正式页面。

## 动效叙事

三个年份构成**一条连续的路**，不是三张轮流淡入的卡片：

- **20%**：轨道从起点向第二阶段延伸；第一张玻璃卡片以 DrawSVG 完整勾画边缘。
- **50%**：真实路径上的进度点准确抵达第二个里程碑；第二张卡片边缘随路径绘制。
- **80%**：连接第三个阶段，第三张卡片边缘逐步勾画；逆向滚动完整反转。
- 所有文字、卡片的玻璃内容始终可阅读；不用 opacity 0→1、Fade Up、抖动或卡片随机飞入。

## 实现

GSAP 3.15.0 核心 + 官方 ScrollTrigger / DrawSVGPlugin / MotionPathPlugin。插件来自固定版本 CDN。路径与卡片轮廓按照 DOM 几何测量；MotionPath 在断点切换时必须**重建官方 tween**（只改 SVG `d` 无法修正其缓存坐标）；第二个节点有独立的中间比例，确保三个节点准确对齐。

设计为静态 GitHub Pages 子路径，可在仓库根目录运行：

```sh
python3 -m http.server 8821
# http://127.0.0.1:8821/previews/gsap-journey-study/
```
