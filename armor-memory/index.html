01 / CORE IDEAS

Memory without lifecycle bureaucracy.

The architecture tried to keep routing deterministic while avoiding recurring human chores such as moving projects between Active and Completed folders or repeatedly approving decisions already made.

01

Stable routing

Object type determines location. Directory structure represents operational purpose rather than lifecycle state.

02

Skill vs. storage

The Skill controls behavior and routing; the durable Vault stores business memory. Derived tools are not allowed to become a second source of truth.

03

Human-cost policy

Routine routing, metadata and deterministic maintenance should be handled by the Agent, reserving human attention for real ambiguity, authority and risk.

02 / ARCHITECTURE

A small set of explicit layers.

The repository stores architecture, router code, tests and maintenance tooling — not live business memory itself.

Shared SkillDefines memory behavior and routing discipline across supported agents.
RouterResolves deterministic destination paths before persistent writes when the destination is not already explicit.
Knowledge qualityRead-only checks for authority, provenance and possible duplicate-title issues.
VaultThe durable business-memory store, deliberately separated from code and diagnostics.

03 / ENGINEERING LESSON

Do not turn memory into a second operating system.

The project progressively removed migration-only tooling and superseded architecture copies from the active tree, relying on Git history instead of keeping old rules beside current rules.

Lifecycle-neutral projects

Named project work stays in one stable project home. Draft, review, publication or retirement status does not require moving the source between root folders.

Explicit maintenance

No silent self-update or automatic repository-version checking during normal memory work. Updates are initiated deliberately.

Project status in this portfolio

The repository remains featured because it represents a deep multi-agent memory design effort and several useful architecture lessons.
