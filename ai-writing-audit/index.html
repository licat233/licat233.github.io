01 / WHAT IT DOES

Risk signals, not authorship guesses.

The tool measures patterns that can make writing feel formulaic or AI-generated. It explicitly does not output an “AI probability” and does not claim to know who wrote the text.

01

Deterministic scan

The CLI audits locally and records stable findings, input SHA-256 and a ruleset/config fingerprint.

02

Fact-preserving repair

When the user asks for a full polish, the Agent rebuilds the article while preserving supplied facts, protected text and factual limits.

03

Tool-agnostic Skill

The same SKILL.md is designed for Codex, Claude Code and Hermes Agent without requiring an MCP server or provider-specific API.

02 / COMPOSITION

Traceable ideas, deliberately integrated.

A project counts as an active component only when its ideas or rules are actually integrated. Merely reviewed repositories are not presented as part of the skill.

03 / USE

Run the scanner locally.

The CLI implements detect mode. Full repair is intentionally an Agent workflow rather than a fake CLI mode that silently behaves like detection.

python3 scripts/audit.py article.md \
  --mode detect \
  --language auto \
  --profile general \
  --format markdown
Protected content includes quotations, code, tables, YAML front matter, HTML attributes, legal text and attributed third-party text. Findings may be reported there, but repair rules must not rewrite it casually.

General by design

Company-specific brand facts, product constraints, legal policies and private editorial rules do not belong in this public skill. Those are intentionally left to downstream integrations or private overlays.
