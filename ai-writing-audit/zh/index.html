01 / 它做什么

判断风险信号，不猜作者身份。

这个工具测量的是容易让文本显得公式化或“像 AI”的写作模式；它明确不输出 AI 概率，也不声称能判断文章是谁写的。

01

确定性扫描

CLI 在本地执行审阅，并记录稳定 finding、输入 SHA-256，以及规则集 / 配置指纹。

02

保留事实的修复

用户要求全文润色时，Agent 重建文章结构，同时保护已有事实、受保护文本和事实边界。

03

Agent 无关

同一份 SKILL.md 面向 Codex、Claude Code 与 Hermes Agent，不要求额外 MCP 服务或厂商 API。

03 / 使用

扫描在本地完成。

CLI 只真正实现 detect；全文 repair 是 Agent 工作流，而不是让一个未实现的 CLI 模式假装已经修复文章。

python3 scripts/audit.py article.md \
  --mode detect \
  --language auto \
  --profile general \
  --format markdown
引用、代码、表格、YAML front matter、HTML 属性、法律文本和归属明确的第三方文本都属于保护内容。可以报告其中的问题，但不能为了“去 AI 味”随意改写。

它被刻意做成通用 Skill

公司专属事实、品牌规范、产品限制、法律规则和私有编辑政策不应该写死在这个公开项目里；这些内容应由下游集成或私有 overlay 提供。
