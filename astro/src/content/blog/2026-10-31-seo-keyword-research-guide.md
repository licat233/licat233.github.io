> 更新：V1.2（2026-10-31，补充竞品页面布局对照）  
> 定位：可迁移到 B2B、跨境电商、SaaS 和一般独立站的关键词研究操作指南  
> 范围：研究方法和决策规范；不是搜索引擎排名承诺、站点改版授权或某家工具的使用说明书

## 1. 目标与完成定义

关键词研究不是“导出尽可能多的词”，而是完成 **业务问题 → 用户搜索需求 → 关键词簇 → 唯一主要页面 Owner → 可执行任务 → 效果验证** 的决策链。

开工前确定五件事：

1. 网站真实供应的产品/服务、无法供应的边界；
2. 目标买家、有效转化（例如 B2B 合格询盘而非泛流量）；
3. 国家、语言和设备范围；
4. 现有可用 URL、页面类型和当前商业路径；
5. 搜索数据来源、预算上限、是否已经有 GSC/GA4 数据。

**完成度必须分层标注**：

| 层级 | 可以声称完成的条件 | 不代表 |
| --- | --- | --- |
| A 词根与候选词 | 主要业务、产品别名、应用、采购术语和问题词已覆盖 | 已覆盖所有用户查询 |
| B 指标与 SERP | 关键市场有注明日期的实际返回指标及代表性 SERP 检查 | 搜索量是真实点击；SERP 长期不变 |
| C 页面映射 | 保留词已分簇并指派现有/拟建 URL 或 HOLD 理由 | 页面已经改动、排名已经提升 |
| D 页面实施 | 实际页面经核对、修改并验收 | 搜索引擎已收录 |
| E 商业效果 | GSC/GA4/询盘等第一方数据足以复核效果 | 因果关系必然成立 |

可以完成 **A–C 研究决策**，但若 D/E 未完成，必须明确说明。不能因为工具返回零行、账户未连接或额度不足就将缺失标为 0 或 PASS。

## 2. 首先盘点网站，而不是先买数据

对已有网站，导出或列出 Canonical URL、页面 Title/H1、主要产品类别、详情页、解决方案、技术资源、应用页和博客页。记录页面是否仍存在、是否可索引、是否有真实产品/技术材料、主要询价或转化入口。

**顺序：现有页面 → 目标买家任务 → 词根**。这样可避免为了每个新发现的词新建薄页面。

注意：品牌方向与关键词的短期投入优先级不同。首页表达完整业务，主力产品线可以单独作为获客优先级；不要让单个高流量词吞并整站定位。

## 3. 挖词：从真实业务构造词根

为每条业务线分别收集：

| 角度 | 示例（示意，不是实时数据） |
| --- | --- |
| 产品名/同义词 | LED shelf lighting / shelf lights |
| 技术/结构 | COB LED strip / magnetic rigid bar / 24V |
| 应用场景 | gondola shelf lighting / supermarket display |
| 采购修饰 | manufacturer / supplier / OEM / custom |
| 选型问题 | how to install / wiring / vs / compatibility |
| 客户语言 | 来自真实询价、销售邮件、规格书及客服记录的表达 |

先核对产品是否真实可供应，避免将不存在的“整套货架”“无线感应供电”“全系列兼容”当成词根。

英文词根不应直接批量翻译为其他语言的 SEO 决策；按市场重新核对当地专业术语和 Google SERP。

## 4. 收集数据：避免重复采购研究

推荐优先级：

1. **已有研究**：检查是否有最近 30 天同市场、同词、同工具的数据、日期和明确限制；不要重复购买。
2. **第一方数据**：若已有 GSC，提取 Query、Page、Country、Clicks、Impressions 和 Position；GA4 用于观察自然搜索落地页和有效转化。只查用户已授权的正确站点属性。
3. **关键词工具**：Semrush Keyword Magic / Keyword Gap、Ahrefs 或 DataForSEO 等；按市场批量采集主要词根、同义词和竞争页面排名词。
4. **定向 SERP**：对高价值或意图有歧义的词，抽查实际搜索结果类型及前列 URL。
5. **销售/产品事实**：客户问法、真实型号、供货边界、技术证据，可否支撑内容。

先用 5–10 个代表性词验证工具能返回有效数据、预算能否覆盖，再扩展；**外部服务明确返回额度不足时，停止付费请求，复用缓存，记录阻断原因，不默认充值或换工具继续烧钱。**

Semrush 不是唯一强制工具；自动聚类只能生成候选，不可直接当最终页面规划。竞争域名按实际相关性选择，几十个竞品不是硬指标。

### 4.1 数据最小字段

**关键词研究总表（建议 CSV/Sheet）**

`keyword,market,language,volume,kd,intent,source,captured_at,metric_status,relevance,cluster_id,notes`

- volume / KD / CPC 为工具估算，标清数据平台、国家、日期与口径；
- metric_status 区分 RETURNED、NULL、NOT_QUERIED、ERROR，不把缺值当作 0；
- 相近变体可能共用搜索量，**不得直接求和**；
- 竞争广告指标、自然搜索 KD、CPC 和实际业务成交价值互不等价；
- 同一关键词不同国家分行保存；不同工具的结果不做无理由平均。

## 5. 清洗：留住重要长尾，排除业务错配

去重时规范空格、大小写和精确重复；**电压、尺寸、工艺、材料、屏幕技术和不同型号不可因字面相似而合并**。

采用四种状态：KEEP（相关）、REVIEW（待验证）、EXCLUDE（确认不匹配）、BRAND（自有或竞品品牌单独分析）。

对低搜索量、高采购意图的词保留 REVIEW/KEEP，不机械删除。对没有真实产品证据或消费者意图强烈的泛词可 HOLD，而不是为了搜索量强行优化。

## 6. 搜索意图：以目标市场的 SERP 为准

常见类型：信息型、导航型、商业调研型、交易型；一个词可以混合多种意图。

对重要词记录：

- 目标国家、语言、检查日期；
- 搜索结果主要返回商品详情、分类、厂商、技术指南、DIY 家用内容还是商城；
- 主要排名页面 URL 和用户任务；
- 企业现有哪种页面能满足相同任务；
- **明确是否只得到历史快照，而不是现时实测**。

典型风险：包含 “shelf lighting” 的词可能返回厨房家具灯，而非零售货架；“power track” 可能指墙壁插座导轨，而非零售低压导电轨；“transparent screen” 可能指 OLED 而非 LED Film。字面相似不等于相同客户需求。

## 7. 聚类：一个主要用户任务对应一个页面 Owner

聚类判断顺序：真实产品类型 → 买家任务 → SERP 页面类型与 URL 重合 → 现有页面能否完整满足。

例子：

- LED Shelf Lights / LED Shelf Lighting：**候选同簇**，需按市场复核。
- LED Shelf Lighting Manufacturer：供应能力意图，先检查现有分类/制造能力页能否承接，不强行独立建页。
- How to Install LED Shelf Lighting：安装任务，可能是指南或现有产品页的技术小节。
- 24V Power Track：应与墙面插座导轨和感应式无线供电区别。
- Electronic Shelf Labels 与 Digital Shelf Labels：可能同簇，但与 Animated Full-color LED/LCD Displays 不等价。

**SERP overlap** 仅为辅助，不设普适的固定比例阈值。对最终分组标注 CONFIRMED_SERP / HISTORICAL_SERP / HYPOTHESIS；不能用自动聚类代替人工核查。

## 8. 映射页面：优先现有 URL

**页面规划表（建议 CSV/Sheet）**

`cluster_id,primary_keyword,secondary_keywords,search_intent,market,target_url,page_type,action,priority,evidence_status,notes`

| 页面角色 | 应承接的任务 | 不应做的事 |
| --- | --- | --- |
| 首页 | 品牌、业务导航、市场定位 | 抢所有产品词 |
| 系统/产品总览 | 一条业务的供应范围和采购入口 | 用不同系统的词堆满页面 |
| 产品家族/分类 | 一类产品的选择与比较 | 与每个具体型号页重复 |
| 产品详情（PDP） | 真实型号、规格、适配、询价 | 给整个系列承诺单个型号参数 |
| Solution / Application | 解决方案、应用约束、集成任务 | 假称已有未验证集成能力 |
| Technical / Blog | 安装、对比、选型、技术问题 | 为每个变体制造重复文章 |
| Projects / Resources | 可验证项目证据、图纸、目录 | 冒充交易性产品页 |

每簇决策：KEEP（现有页面胜任）、OPTIMIZE（补实质内容）、NEW（有独立搜索任务且内容证据充分）、HOLD（待证据）、EXCLUDE（不做）。

多个 URL 排同一词不自动构成“关键词蚕食”；先看用户任务、实际内容和 GSC 的 Query×Page 数据，未经证据不批量合并、删除或改 301。

SEO 映射不是直接授权改 Title、H1、Canonical、路由、抓取权限或上线。

## 9. 优先级：不追求高流量幻觉

先问“能否真实供货？是否目标采购方？” 再看搜索量、竞争、CTR/CPC、已有页面可用性和制作成本。

| 级别 | 使用条件 |
| --- | --- |
| P1 | 业务强相关、真实供货证据充分、采购路径明确、可以复用现有 URL |
| P2 | 相关但需补技术材料或存在竞争、内容成本 |
| P3 | 长期内容机会，短期商业价值未验证 |
| HOLD | 意图、指标或在售/认证/软件兼容证据不充分 |

若预算有限，优先每条核心业务 1–3 个最有资格的 Owner，而不是一次生成几十个新页面。涉及国际化时把 **页面内容共用架构** 与 **各国关键词研究** 分离。

## 10. 执行和验收

每个优先页面填写简短 Content Brief：搜索任务、主次关键词、当前 URL、缺少的采购信息、真实产品/型号证据、关键内部链接、CTA、国家语言、预期指标。

页面层面验证：实际 URL、HTML Title/H1、Canonical、主内容、产品资料、可用链接和询盘入口；Google 不规定标题固定字符、关键词密度或统一字数，网站内部约束需独立标注。

效果层面验证：GSC 查询与页面的展示/点击/CTR/排名，GA4 自然搜索落地与真实转化事件，必要时用 CRM/人工资格审核确认询盘质量。注意归因差异、观察期、季节性、市场和工具口径。

如果 robots.txt 仍整站禁止抓取或 GSC 未绑定，**只能交付策略/页面规划，不能声称已完成搜索效果验证**。开放抓取、调整索引或生产发布必须另获对应授权。

## 11. 失败与阻断处理：来自实战的修订

1. **旧研究有效但有快照时效**：复用有日期的数据，重要新决策优先验证关键 SERP；不机械重买。
2. **关键词工具额度用尽**：立即停止收费请求，保存数据缺失状态；不要推测搜索量或 KD。
3. **GSC 属性存在但项目未绑定**：区分“账户有该站”与“当前研究项目可查询”；只凭前者不能汇报实际点击/排名。
4. **页面已有专业分类**：先复用 Owner，禁止为了“一个关键词一页”制造新 URL。
5. **历史产品型号资料**：可用于技术事实溯源，但不能据此承诺现行生产、库存、认证和跨型号兼容。
6. **多语言站点**：已发布语言数不等于已完成相应市场的独立关键词调研；明确国家、优先级和未覆盖范围。
7. **研究与发布分开**：A–C 完成后可交付建议；D 实施和 E 转化验证是独立的下一阶段。

## 12. 最小交付清单

- 已定义产品范围、目标市场、有效转化；
- 有带来源与日期的研究总表，Null 与真实零值分开；
- 对 P1 歧义词至少有可追溯的 SERP 判断或显式待验证标识；
- 有关键词簇与页面 Owner 表，现有 URL 经过源代码/页面清单核对；
- 各项决策有 KEEP / OPTIMIZE / NEW / HOLD / EXCLUDE 和商业理由；
- 标出指标有效期、未完成市场、工具费用、GSC/GA4/索引阻断；
- 每项后续任务可执行，不把文档研究自动转换为网站改动。

## 13. 竞品页面布局对照：从关键词簇推进到真实内容差距

> V1.2 新增。对照方法以可复查的公开网页和已授权的页面资料为依据；结构观察不是 Google 排名或转化率证明。

**竞品对照并非搜集多少个网站标题，而是判断某种页面为什么能完整回答某种搜索任务，然后检查本站是否已有等价内容。**

### 13.1 先选具有同一用户任务的页面

不要用竞争对手的产品详情页去证明自己应当新建分类页，也不要将业务模式、地域和渠道差异当成 SEO 差距。

按同一关键词簇分别选：业务 Hub、产品分类、具体产品 PDP、解决方案、专业指南或问题型 FAQ。外部网页若与本企业并非同一产品/买家，标记“参考”而非直接竞争。

### 13.2 逐页记录九个字段

| 字段 | 记录目的 |
| --- | --- |
| Competitor URL | 直接可复查的网页，不只写域名 |
| Target task / cluster | 观察其处理什么买家问题；**不要未查排名就说“排名关键词”** |
| Title / H1 | 记录页面直接可见或可验证的真实文字；无法确认则写未知 |
| Main content | 商品数量、具体型号参数、选型对照、安装说明、FAQ 与资料 |
| Internal links | 分类 → 商品、内容 → 产品/资料、产品 → 采购等实际链接 |
| Our owner URL | 网站现有页面和所属业务，区分源码与生产环境 |
| Already exists? | 是否已有对应内容；已完成不得重复列为缺口 |
| Evidence / limitation | 实测、源码、历史文件、内容推断及数据时点 |
| Action / priority | KEEP、OPTIMIZE、VERIFY、HOLD，及最小实际变更 |

### 13.3 不要把竞品销量、排名或技术承诺“推”出来

- 看到竞品页结构完整，不代表已经测得它自然搜索排名更高；排名、自然流量、关键词份额需要相应来源和市场数据。
- 竞品型号规格、认证、库存、软件平台集成及兼容性只适用于经过核实的对应产品，不能移植到本企业。
- 不把“页面词更精确”误写成必定要改 URL。只有搜索任务、独立内容价值、现有页面不足三个条件同时成立，才考虑新页。
- 同行的泛技术指南可能面向终端消费者；B2B 网站应优先解决能推动采购的选型、规格、安装和报价问题。

### 13.4 内部链接随 Owner 一起审核

每个高优先级关键词簇至少核对实际页面是否能够：

1. 从主题/业务入口到达对应产品家族或解决方案；
2. 从家族与解决方案到达有效的具体型号/技术资料；
3. 从具体型号或指南返回正确业务，并进入真实有效的询价/购买路径。

上述是**相关性检查**，不要求每个页面固定添加若干链接，也不默认新建技术服务。先修断链与错误意图链接，再考虑非必要的链接扩展。

### 13.5 案例中的实际修正

对比 COB LED Strip 分类页时发现，竞品可以在列表直接显示电压、功率、宽度、切割间距；但另一个网站可能只有旧型号和未确认的规格版本。**正确任务不是立刻把参数填进所有卡片**，而是先核实少量现售型号，再评估是否用现有家族页增加紧凑的规格对照。

对比零售 Shelf Lighting 分类页时还要注意：同名分类可能主要展示连接器和电轨配件，不能误认为它已经完整覆盖所有货架照明灯具。**必须看实际商品和信息，而不仅看标题。**

### 13.6 停止条件

对照研究完成后，若发现已有关键词 Owner、买家指南、型号链接和询盘入口已经满足用户任务，应直接标记 **KEEP / NO ACTION**。只有被明确证明的缺口才进入实施队列；不能为了“对标优秀网站”继续制造同义词页面或泛 SEO 博客。
