**Universal Product SEO Naming Guidelines · V1.2**

## 一、核心原则：先理解产品，再决定如何命名

产品名称不是简单地把产品参数、关键词和营销卖点拼接在一起。

一个好的产品 SEO 名称，应该让买家在看到名称的第一时间，就能理解：

1. 这是什么产品？
2. 这个产品主要用在哪里？
3. 它有什么值得关注的特点？

同时，还要考虑目标市场的买家通常使用什么词汇，在 Google、Bing、电商平台等渠道寻找这类产品。

因此，产品命名必须同时满足三个要求：

- **搜索匹配**：使用目标买家真实使用的产品关键词。
- **语义准确**：名称准确描述产品的类型、用途和特点。
- **自然易读**：符合目标语言的正常表达习惯，而不是关键词拼接。

核心原则：

**先确定产品是什么，再确定买家怎么搜索，最后决定哪些信息值得放进名称。**

本规范适用于 B2B、B2C、跨境电商、独立站、企业官网及各类产品展示页面。

## 二、产品名称的组成结构

### 2.1 推荐命名公式

产品 H1 名称可以参考以下结构：

**修饰词 + 核心产品关键词 + 应用场景 + 差异化特征**

英文结构示意：

`[Modifier] + [Core Product Keyword] + for [Application] + with [Key Feature]`

各组成部分的作用：

| 组成部分 | 作用 | 示例 |
|---|---|---|
| Modifier | 描述产品的重要属性 | White |
| Core Product Keyword | 明确产品是什么 | LED Lens Strip |
| Application | 明确主要应用场景 | for Lightboxes |
| Key Feature | 突出产品差异化特点 | with Wide Beam Optics |

并不是每个产品都必须包含上述四个部分。

应该根据产品的实际情况，选择最有搜索价值、最能帮助买家理解产品的信息。

### 2.2 关键词顺序可以调整

上述公式只是信息组织方式，不是必须严格遵守的固定句式。

一般情况下，核心产品关键词应尽量靠前，避免被无关修饰词淹没。

但如果某个修饰词本身具有较高的搜索价值，或者与核心关键词组合后能够形成更精准的搜索词，也可以放在核心关键词之前。

例如：

**White LED Lens Strip for Lightboxes with Wide Beam Optics**

其中：

- White：产品颜色属性。
- LED Lens Strip：核心产品关键词。
- for Lightboxes：主要应用场景。
- with Wide Beam Optics：差异化技术特点。

这种表达既保留了核心关键词，又自然地补充了买家关心的信息。

### 2.3 不要强制使用固定介词

`for` 和 `with` 只是常见的表达方式，不是必须使用的语法模板。

如果不使用这些介词，产品名称反而更加自然，就应该调整结构。

最终以目标语言的语法自然、语义准确为准，而不是为了套公式而牺牲可读性。

## 三、确定产品名称之前，必须完成的四项判断

这是整个命名流程中最重要的部分。

### 3.1 确定核心产品关键词

核心产品关键词（Core Product Keyword）是整个产品名称中最重要的部分。

它必须准确说明产品属于什么类别，以及买家通常如何称呼这类产品。

选择时应考虑：

1. 目标市场的买家通常使用什么名称搜索这类产品？
2. 行业内最通用、最容易理解的产品名称是什么？
3. 竞争对手及行业网站通常使用什么词汇？
4. 搜索结果中出现的产品，是否真的与我们销售的产品属于同一类别？

关键词研究可以参考：

- Google、Bing 等搜索引擎的搜索结果及相关搜索。
- Google Search Console 等搜索表现数据。
- Ahrefs、Semrush 等关键词研究工具。
- 行业竞争对手的网站。
- Alibaba.com、Amazon 等电商及 B2B 平台的买家搜索词。
- 目标市场的行业目录、专业网站及产品分类。

需要注意：

搜索量高不代表关键词一定适合。

如果一个关键词搜索量很高，但搜索结果对应的是另一种产品，就不能为了流量而使用它。

**核心关键词必须同时满足搜索相关性和产品准确性。**

另外，不要为了覆盖更多搜索词，把多个不同的产品概念塞进同一个名称。

例如，不应该为了覆盖关键词，把 LED Strip、LED Light Bar、LED Lighting 等不同概念全部堆叠在一起。

一个产品名称应该有一个明确的核心产品关键词。

### 3.2 确定主要应用场景

应用场景（Application）用于告诉买家，这个产品主要适合用在哪里。

优先选择：

- 产品最主要的实际用途。
- 最有商业价值的应用市场。
- 买家最可能使用的搜索场景词。

例如：

- for Lightboxes
- for Retail Shelving
- for Display Cabinets
- for Backlit Signage

不要使用过于宽泛、无法帮助买家判断产品用途的表达，例如：

- for Commercial Use
- for Various Applications
- for Multiple Industries

如果一个产品可以应用于多个行业，也不意味着必须把所有行业都写进产品名称。

优先突出最重要的应用场景，其他应用可以放在产品摘要、正文和 FAQ 中介绍。

如果产品本身没有明确的特定应用场景，则不必强行添加这一部分。

### 3.3 确定重要修饰词

修饰词（Modifier）用于补充产品的重要属性。

例如：

- White：颜色。
- Slim：外形。
- Flexible：结构或柔性特征。
- Magnetic：磁吸属性。
- Wireless：无线供电或通信属性。

修饰词应满足两个条件：

1. 确实能够描述产品。
2. 对买家识别产品或搜索产品具有实际价值。

不要为了增加关键词数量，把所有产品属性都放进名称。

例如，电压、尺寸、重量、色温等参数，通常更适合放在规格表和 Meta Description 中，而不是全部塞进 H1。

### 3.4 确定差异化特征

差异化特征（Key Feature）用于告诉买家，这款产品有什么值得关注的技术特点、功能或结构优势。

例如：

- with Wide Beam Optics
- with Magnetic Mounting
- with Wireless Power Supply
- with Full-Color Display

优先选择一个最有价值的差异化特征。

如果产品确实具有两个非常重要、且买家关注度较高的特点，可以适当增加，但不能为了覆盖关键词而堆砌。

尤其需要避免使用没有实际信息量的营销词汇：

- Excellent Quality
- Best Price
- High Quality
- Professional Solution
- Premium Product

除非有明确的事实依据，否则不要把营销承诺当作产品技术特点。

## 四、产品名称必须遵循的 8 条原则

### 原则 1：核心产品关键词优先

核心产品关键词必须清晰、准确，并尽量出现在名称前部。

不能为了增加关键词覆盖，把真正重要的产品名称放在标题后面。

### 原则 2：一个名称只突出一个核心产品概念

不要把同义词、近义词以及不同产品类别的名称拼接在一起。

其他相关关键词可以放在：

- 产品摘要。
- 产品详情正文。
- 产品规格。
- FAQ。
- 图片 Alt。

不要让一个产品名称承担整张网页的全部关键词覆盖任务。

### 原则 3：应用场景要具体

优先选择真实、明确、有商业价值的应用场景。

如果应用场景对买家搜索和产品识别没有帮助，就不必强行加入。

### 原则 4：修饰词必须有实际意义

颜色、尺寸、结构、供电方式、安装方式等信息，只有在能够帮助买家识别产品时才值得放入名称。

不要为了 SEO 而添加一连串形容词。

### 原则 5：差异化特征只选最重要的

不要把所有技术参数和功能都写进名称。

名称负责建立产品认知，具体参数和技术细节由产品正文承担。

### 原则 6：型号根据搜索价值决定是否加入

型号（Model Number）不一定要出现在 H1 中。

如果型号本身具有较高的搜索价值，或者买家习惯通过型号寻找产品，可以将其加入名称。

如果型号主要用于内部识别和产品管理，则放在：

- 产品规格。
- 产品摘要。
- Meta Description。
- 产品正文。

不必为了保留型号而牺牲核心关键词的展示位置。

### 原则 7：禁止关键词堆砌和无依据宣传

禁止：

- 重复堆叠同义关键词。
- 同时加入多个不相关的应用场景。
- 重复出现产品核心关键词。
- 使用没有事实依据的认证、性能和技术承诺。
- 使用与实际产品不符的行业术语。

所有产品描述必须有真实产品资料作为依据。

不能因为某个关键词搜索量高，就擅自把产品描述成具有该功能或性能。

### 原则 8：必须符合人类阅读习惯

SEO 不只是让搜索引擎理解产品，也是为了让买家快速理解产品。

产品名称必须符合目标语言的正常表达习惯。

如果一个名称虽然包含很多关键词，但读起来像机器拼接出来的句子，就应该重新组织。

**自然、准确、容易理解，比机械地覆盖更多关键词重要。**

## 五、H1、SEO Title 与 Meta Description 的区别

三者不是简单重复，而是承担不同职责。

以下使用一款 LED 透镜灯条作为演示案例。

| 项目 | 主要职责 | 示例配置 |
|---|---|---|
| H1 | 完整表达产品名称 | White LED Lens Strip for Lightboxes with Wide Beam Optics |
| SEO Title | 精炼表达核心关键词、应用场景和品牌 | White LED Lens Strip for Lightboxes | [Brand Name] |
| Meta Description | 补充型号、重要参数、技术特点和应用价值 | 介绍 DC24V、6000–6500K、约170°光学设计及单颗 LED 可裁剪特性 |

### 5.1 H1：完整产品名称

H1 是产品详情页最重要的可见标题。

要求：

- 清晰说明产品是什么。
- 尽可能体现主要应用场景。
- 可以体现最重要的差异化特征。
- 符合正常语言表达习惯。
- 英文名称建议 5–12 个单词。

5–12 个单词是推荐范围，不是必须凑足的数量。

如果更短的名称已经能够准确表达产品，就没有必要为了达到单词数量而增加无价值的修饰词。

如果使用其他语言，应根据该语言的表达习惯调整名称结构，不应机械套用英文单词数量标准。

### 5.2 SEO Title：搜索结果标题

SEO Title 主要面向搜索引擎结果页。

推荐结构：

`Core Product Keyword + Application | [Brand Name]`

要求：

1. 优先保留核心产品关键词。
2. 尽量保留主要应用场景。
3. 根据实际情况加入品牌名称。
4. 避免简单复制 H1 中的所有内容。
5. 不要为了增加关键词而牺牲标题可读性。

**英文 SEO Title 长度建议：约 50–60 个字符。**

这是编辑目标，不是搜索引擎规定的硬性字符上限。搜索结果的实际展示长度还受到设备和像素宽度等因素影响。

如果标题超过目标范围，优先精简次要修饰词，不要为了控制长度而删除核心产品关键词。

### 5.3 Meta Description：搜索结果摘要

Meta Description 的主要作用是补充产品信息，让买家在搜索结果中了解产品的具体特点。

推荐包含：

- 产品型号（如果有）。
- 重要技术参数。
- 核心功能或结构特点。
- 主要应用价值。
- 适当的商业信息。

例如，LED 透镜灯条可以介绍：

- DC24V。
- 6000–6500K。
- 约170°光学设计。
- 单颗 LED 可裁剪。

要求：

1. 不要简单重复 H1。
2. 不要把所有规格参数都塞进去。
3. 优先选择最有价值、最能帮助买家判断产品的信息。
4. 不得添加产品资料中没有证实的参数。
5. 使用自然、易读的语言表达。

**英文 Meta Description 长度建议：约 140–160 个字符。**

同样，这只是编辑参考范围，不代表搜索引擎一定会完整展示这些字符。搜索引擎可能根据搜索词重新生成摘要。

## 六、字符数和单词数必须使用程序校验

这是产品 SEO 配置中必须执行的技术规范。

AI 对字符数和单词数的估算可能出现错误，因此不能直接相信 AI 报告的数字。

必须使用 Python 或其他可靠工具进行实际计算。

### 6.1 校验标准

| 项目 | 校验内容 | 英文推荐范围 |
|---|---|---|
| H1 | 英文单词数 | 5–12 words |
| SEO Title | 字符数（含空格和标点） | 约 50–60 characters |
| Meta Description | 字符数（含空格和标点） | 约 140–160 characters |

### 6.2 Python 校验代码

```python
import re
from collections import Counter

fields = {
    "H1": "White LED Lens Strip for Lightboxes with Wide Beam Optics",
    "SEO Title": "White LED Lens Strip for Lightboxes | Brand Name",
    "Meta Description": "在这里填写实际的 Meta Description"
}

for name, value in fields.items():
    value = value.strip()

    # 计算英文单词数
    words = re.findall(
        r"[A-Za-z0-9]+(?:[-'][A-Za-z0-9]+)*",
        value
    )

    # 检查重复单词
    counts = Counter(word.lower() for word in words)
    duplicates = [
        word for word, count in counts.items()
        if count > 1
    ]

    print(f"\n{name}")
    print(f"Characters: {len(value)}")
    print(f"Words: {len(words)}")
    print(
        f"Repeated words: "
        f"{', '.join(duplicates) if duplicates else 'None'}"
    )
```

注意：

- Python `len()` 计算实际字符串长度，包含空格和标点。
- 英文产品标题应直接使用实际准备发布的完整字符串进行检测。
- 单词数量使用程序计算，不允许 AI 凭感觉报告。
- 重复单词检测只是辅助检查，不代表所有重复词都属于关键词堆砌。
- 字符数合格不代表搜索结果展示宽度一定合格，SEO Title 还应结合搜索结果预览检查。
- 对于非英语内容，应根据目标语言采用适当的分词和字符统计方法。

如果 AI 当前没有实际运行 Python 或其他字符统计工具的能力，就必须明确说明尚未完成程序校验，不能虚构校验结果。

## 七、通用产品 SEO 命名工作流程

以后每次新增产品，都按照以下流程执行。

### Step 1：理解产品

先阅读产品资料，包括：

- 产品图片。
- 产品规格书。
- 产品宣传册。
- 产品功能说明。
- 产品结构及应用资料。

先确认产品到底是什么，不要在尚未理解产品的情况下直接生成 SEO 名称。

### Step 2：研究核心产品关键词

研究目标市场买家的真实搜索习惯，确定最适合这个产品的核心产品关键词。

如果存在多个候选关键词，应比较：

- 搜索意图。
- 产品匹配程度。
- 行业通用程度。
- 搜索竞争情况。
- 买家使用习惯。

最终选择一个最适合的核心产品关键词。

如果缺乏搜索数据，应明确区分行业通用术语与已经通过数据验证的搜索关键词，不得编造搜索量。

### Step 3：确定主要应用场景

从产品实际用途出发，选择最主要的应用场景。

不要为了扩大关键词覆盖而罗列所有可能的应用。

### Step 4：提取重要产品属性与差异化特征

从真实产品资料中选择：

- 最有价值的修饰词。
- 最重要的差异化特征。

优先考虑买家关心、能够帮助产品识别和区分的信息。

### Step 5：生成 H1

根据前面的研究结果组织产品名称。

允许调整词语顺序，不要求机械遵守固定公式。

必要时可以生成几个候选名称进行比较，但最终只保留一个最合适的名称。

### Step 6：生成 SEO Title

在 H1 的基础上进行精简。

优先保留核心关键词和主要应用场景，并根据实际网站的品牌规范添加品牌名称。

### Step 7：生成 Meta Description

补充型号、重要参数、技术特点及应用价值。

不要简单复制 H1，也不要为了填充字符而加入无关内容。

### Step 8：程序校验与语义验收

使用程序检查：

- H1 单词数量。
- SEO Title 字符数量。
- Meta Description 字符数量。
- 重复关键词。
- 型号及参数准确性。

最后人工检查语言语法、搜索意图和产品事实。

## 八、每次产品命名的标准交付格式

为了方便审核和后续维护，每次完成产品命名后，按照以下格式交付：

| 项目 | 输出内容 |
|---|---|
| Core Product Keyword | 核心产品关键词 |
| Keyword Research | 关键词选择依据 |
| Primary Application | 主要应用场景 |
| Modifier | 重要修饰词 |
| Key Feature | 差异化特征 |
| H1 | 最终产品名称 |
| SEO Title | 最终搜索标题 |
| Meta Description | 最终搜索摘要 |
| Validation | 程序校验结果 |

如果某个组成部分不适用于产品，可以留空，不需要为了填满表格而人为添加内容。

## 九、最终验收标准

一个合格的产品 SEO 名称，必须同时满足以下条件：

1. **产品准确**：名称真实反映产品类别，不会让买家误解产品。
2. **关键词准确**：核心关键词符合目标买家的搜索习惯，并且与产品高度相关。
3. **用途明确**：买家能够快速理解产品主要应用于什么场景。
4. **特点突出**：名称能够体现产品最重要的差异化价值。
5. **表达自然**：语言符合正常阅读习惯，没有关键词堆砌。
6. **信息真实**：所有产品属性、技术特点和性能描述都有资料依据。
7. **程序合格**：字符数和单词数已经经过实际工具校验。
8. **分工合理**：H1、SEO Title、Meta Description 各司其职，不是简单重复。

## 十、最终原则：统一命名逻辑，不统一机械句式

所有行业、所有企业的产品，都可以遵循统一的 SEO 命名逻辑。

但是，统一标准不等于所有产品都必须使用相同的句式。

不同产品的搜索习惯、应用场景、技术特点和商业价值都不一样。

有些产品最重要的是产品类别，有些产品的关键搜索入口是安装方式，有些产品则需要突出材料、功能、结构或者特殊技术。

这些差异都应该反映在最终名称中。

不要为了形式上的统一，让不同产品的名称变得千篇一律。

**我们需要统一的是判断逻辑，而不是标题模板。**

最终目标是让搜索引擎准确理解产品，让买家快速找到产品，并且在看到产品名称时，就能明白这个产品是否符合自己的需求。
